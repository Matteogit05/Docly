# Docly
Docly is a web-app where you can book a medical exam or simple appointments with your main doctor.


### Main features
- booking an appointment with a doctor
- chat sessions that provide messages exchanging between doctor and patient
- attachments exchanging



Docly is built with ASP.NET Blazor Server (.NET 9)
